Installation

Prêt en 3 minutes

Fonctionne sur Windows avec Python 3.10+.

1
Cloner le dépôt
Télécharge le projet depuis GitHub dans C:\NutriTracker\
git clone https://github.com/Victorlegeek/Nutri-Tracker C:\NutriTracker
2
Lancer le script d'installation
Exécute install_nutri.bat en tant qu'administrateur — il installe toutes les dépendances automatiquement.
install_nutri.bat (clic droit → Exécuter en administrateur)
3
Configurer la clé IA (optionnel)
Pour l'enrichissement automatique, ajoute ta clé Groq API dans config.json
echo {"groq_api_key": "gsk_..."} > config.json
4
Lancer l'application
Double-clique sur lancer_nutri.bat ou lance via Python
python main.py

Intelligence Artificielle

IA gratuite intégrée

Deux systèmes IA distincts — analyse locale et enrichissement via Groq.

✓ Zéro API — Local

🧠 Analyse nutritionnelle

Système de règles expert embarqué qui analyse chaque aliment et la journée entière sans connexion internet.

  • Détection excès sucres / graisses saturées / sel
  • Score santé de 0 à 100 par aliment
  • Suggestions d'alternatives (Nutella → beurre de cacahuète)
  • Conseils personnalisés selon sèche / maintien / masse
  • Analyse globale de la journée alimentaire
★ Groq — Llama 3.3 70B

🤖 Enrichissement automatique

À chaque démarrage, l'IA génère de nouveaux aliments et suppléments et les ajoute à votre base locale.

  • 8 nouveaux aliments générés par session
  • 3 nouveaux suppléments sportifs
  • Détection et suppression des doublons
  • Valeurs nutritionnelles précises pour 100g
  • Thread arrière-plan — ne bloque pas l'UI
  • Gratuit — inscription sur console.groq.com
