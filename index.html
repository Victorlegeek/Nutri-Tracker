Fonctionnalites

Tout ce dont vous avez besoin

Une application complete pensee pour les sportifs et les personnes soucieuses de leur alimentation, sans compromis sur la vie privee.

Journal alimentaire quotidien
Enregistrez chaque repas classe par categorie : petit-dejeuner, dejeuner, diner, collation. Navigation par date avec fleches ou bouton "Aujourd'hui". Chaque entree affiche instantanement calories, proteines, glucides, lipides et fibres. Actions rapides : modifier la quantite, dupliquer une entree, supprimer. Le total de la journee est recalcule en temps reel. Analyse nutritionnelle complete de la journee sur simple clic, avec conseils personnalises selon vos objectifs.
journal par repas analyse instantanee
Objectifs intelligents
Calcul automatique de vos objectifs journaliers via la formule Mifflin-St Jeor. Renseignez age, poids, taille, niveau d'activite et objectif (seche, maintien, prise de masse) : calories, proteines, glucides, lipides, fibres, sel et sucres sont calcules en consequence. Les objectifs sont aussi modifiables manuellement a tout moment. Barres de progression en temps reel et repartition calorique par macronutriment.
formule Mifflin-St Jeor
Graphiques de progression
Courbes lisses pour calories, proteines, glucides, lipides et fibres sur 7, 14 ou 30 jours. Ligne d'objectif en pointilles, valeur maximale et moyenne affiches. Graphique en barres comparatif pour voir rapidement les jours ou vous avez atteint vos objectifs. Onglet resume avec min, max, total et pourcentage de l'objectif. Streak et taux de consistance calcules automatiquement.
7 / 14 / 30 jours
Sante et composition corporelle
Saisie quotidienne : poids, tours de taille / cou / hanches / bras / cuisse, hydratation, sommeil, forme subjective, stress, seance du jour et frequence cardiaque. Calculs automatiques : IMC avec categorie, masse grasse via methode US Navy, masse maigre, VO2max estime (formule Uth-Sorensen), poids ideal (Devine) et besoin en eau. Graphique d'evolution du poids avec tendance lineaire.
US Navy / Devine / Uth
Base de donnees alimentaire
Plus de 70 aliments pre-renseignes couvrant viandes, poissons, oeufs, feculents, legumes, fruits, laitiers, oleagineux, legumineuses, complements et boissons. Recherche approximative par nom avec algorithme difflib. Tri par colonne, filtre par categorie, gestion des favoris. Chaque aliment stocke 8 valeurs nutritionnelles pour 100g. Ajout, modification et suppression depuis l'interface.
recherche floue
Supplements et complements
Catalogue de supplements (whey, creatine, omega 3, vitamines, mineraux...) avec dose habituelle et valeurs nutritionnelles par dose. Enregistrement des prises quotidiennes avec heure et notes. Ajout direct d'une prise au journal alimentaire. Suivi hebdomadaire des prises. Les complements (whey, creatine presentes en base) s'integrent naturellement au journal.
prises quotidiennes
Analyse et score sante
Chaque aliment recoit un score sante de 0 a 100 calcule selon sa teneur en proteines, fibres, acides gras satures, sucres et sel. Alertes contextuelles : elevees en sodium, acides gras satures, sucres, ou au contraire riche en fibres et proteines. Suggestions d'alternatives adaptees a votre objectif (seche, maintien, prise de masse). Analyse complete de la journee avec conseils.
score 0-100
Enrichissement IA via Groq (optionnel)
Connexion a l'API Groq (gratuite, aucune carte bancaire requise) pour generer automatiquement de nouveaux aliments et supplements a chaque lancement. Le modele LLaMA 3.3 70B produit des valeurs nutritionnelles realistes et variees, orientees sport et sante. Detection automatique des doublons par comparaison approximative des noms (difflib). L'enrichissement tourne en arriere-plan sans bloquer l'interface. Configurez simplement votre cle dans config.json.
gratuit — console.groq.com LLaMA 3.3 70B
100% local, zero cloud
Toutes les donnees sont stockees en JSON sur votre machine. Aliments, journal, objectifs, sante, supplements : cinq fichiers lisibles et sauvegardables. Backup automatique avant chaque ecriture (.bak). Aucun compte, aucun abonnement, aucune connexion requise sauf si l'IA Groq est activee.
zero telemetrie

Pre-requis

Ce qu'il vous faut

NutriTracker tourne sur Python standard. Un seul paquet est vraiment necessaire.

Python 3.10 minimum requis. Si vous n'avez pas la bonne version ou si les imports echouent au lancement, executez install_nutri.bat en administrateur. Ce script verifie votre version Python, met a jour pip et installe tous les modules automatiquement.

Structure

Organisation du projet

Le projet est volontairement simple : Python pur, pas de framework, donnees en JSON.

NutriTracker/
├── main.py                point d'entree, verification dependances
├── lancer_nutri.bat       raccourci Windows
├── install_nutri.bat      installation automatique des dependances
├── config.json            cle API Groq (optionnel)
├── data/
│   ├── aliments.json      base alimentaire (70+ entrees)
│   ├── journal.json       entrees quotidiennes par date
│   ├── objectifs.json     profil utilisateur et objectifs
│   ├── supplements.json   catalogue et prises quotidiennes
│   └── sante.json         mesures corporelles historisees
├── models/             dataclasses : Aliment, EntreeJournal, Profil
├── database/           lecture / ecriture JSON
├── ui/                 fenetre principale, graphiques, sante
├── nutrition/          analyse, scores, suggestions
└── utils/              enrichissement IA (Groq)

Installation

Lancer NutriTracker

Cinq minutes, pas de compilation, pas de base de donnees a configurer.

1
Cloner le depot
Telechargez les sources via Git ou depuis la page releases GitHub.
bash
git clone https://github.com/Vindows/NutriTracker.git
cd NutriTracker
2
Installer les dependances — Windows
Double-cliquez sur install_nutri.bat en administrateur. Le script verifie Python 3.10+, met a jour pip et installe tous les modules requis et optionnels automatiquement.
batch
# ou depuis le terminal :
install_nutri.bat

Si Python est inferieur a 3.10, le script vous redirige vers python.org automatiquement.

3
Installer les dependances — macOS / Linux
bash
python -m venv .venv
source .venv/bin/activate

pip install ttkbootstrap requests beautifulsoup4 Pillow

Sur Ubuntu/Debian, installez tkinter via : sudo apt install python3-tk

4
Lancer l'application
bash
python main.py

# Windows : double-clic sur lancer_nutri.bat
5
Enrichissement IA Groq — optionnel, gratuit
Creez un compte gratuit sur console.groq.com, generez une cle API et renseignez-la dans config.json. L'application enrichira automatiquement la base d'aliments a chaque lancement via LLaMA 3.
json — config.json
{
  "groq_api_key": "votre_cle_api_ici"
}
